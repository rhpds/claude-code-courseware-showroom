== What You Will Learn

* How to install and configure the Playwright MCP server with Chrome

* How to close browsers and clean up resources

== Key Concepts

The Playwright MCP server gives Claude Code direct browser control. Instead of asking you to open a URL and describe what you see, Claude can navigate, read page content, click buttons, fill forms, and take screenshots on its own.

A "snapshot" returns the page's accessibility tree — a structured view of all the elements Claude can see and interact with. This is more useful than a screenshot because Claude can reason about the elements directly. Think of it as "what a screen reader sees" — structured, actionable, and much richer than raw HTML.

Available interaction tools:

* `browser_navigate` — go to any URL
* `browser_snapshot` — capture page structure as accessibility tree
* `browser_click` — click any element
* `browser_type` — type text into inputs
* `browser_hover` — hover over elements (triggers menus, tooltips)
* `browser_select_option` — choose from dropdowns
* `browser_fill_form` — fill multiple form fields at once
* `browser_press_key` — press keyboard keys (Enter, Tab, Escape, etc.)
* `browser_take_screenshot` — capture visual state as PNG or JPEG
* `browser_close` — clean up browser resources

The pattern is always: snapshot → find element → act → snapshot again.

The server runs locally and controls a local Chrome instance. Chrome must be installed at the standard system path (`/Applications/Google Chrome.app` on macOS). The `@playwright/mcp` package comes from npm.

== Steps Overview

. Install the `@playwright/mcp` package globally via npm
. Smoke test the server with Chrome to ensure it launches
. Write the MCP server config to `~/.claude/settings.json` with full paths
. Restart Claude Code to activate the Playwright MCP server
. Use `browser_navigate` to open a web page
. Use `browser_snapshot` to capture the page's accessibility tree
. Find elements in the snapshot and use `browser_click` to interact
. Use `browser_type` to fill text fields
. Use `browser_take_screenshot` to capture visual state
. Use `browser_close` to clean up resources
