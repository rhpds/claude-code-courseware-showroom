== Key Concepts

=== Vertex AI as Backend Provider

Claude Code can use Google Cloud's Vertex AI instead of Anthropic's direct API. This means your Claude API calls route through your assigned GCP project, which handles billing and quota management through Google Cloud rather than requiring an Anthropic API key.

=== Application Default Credentials (ADC)

ADC is Google's standard mechanism for application authentication. Claude Code uses ADC to obtain authentication tokens from Google Cloud automatically. When you run `gcloud auth application-default login`, you authorize Claude Code to access Vertex AI on your behalf without needing to manage API keys manually.

=== Environment Variables Configuration

Claude Code needs three environment variables to use Vertex AI:

* `CLAUDE_CODE_USE_VERTEX=1` -- tells Claude Code to route API calls through Vertex AI
* `ANTHROPIC_VERTEX_PROJECT_ID=your-project-id` -- specifies which GCP project to bill against
* `CLOUD_ML_REGION=global` -- sets the region for Vertex AI API calls

These can be set in two places: `~/.claude/settings.json` (recommended, works everywhere) and your shell config file (`~/.zshrc` or `~/.bashrc`, ensures new terminals have them). The module sets both to ensure compatibility with all environments.

=== GCP Project Assignment

Your team lead assigns you a GCP project ID. This project must have Vertex AI API enabled and your Google identity must have permission to use it. Without a valid project ID, Claude Code cannot authenticate with Vertex AI.

== Steps Overview

The interactive walkthrough covers:

. **Install gcloud CLI** -- Install the Google Cloud SDK via Homebrew (Mac) or Google's installer (Linux)
. **Install Node.js** -- Claude Code requires Node.js 18 or higher
. **Install Claude Code** -- Use the native installer (recommended for auto-updates) or npm
. **Authenticate with Google Cloud** -- Sign in with your @redhat.com account via `gcloud auth login`
. **Set up Application Default Credentials** -- Authorize Claude Code to use Vertex AI via `gcloud auth application-default login`
. **Set GCP project** -- Configure your assigned GCP project ID with `gcloud config set project`
. **Write Vertex AI environment variables** -- Write the three required environment variables to both `~/.claude/settings.json` and your shell config

Each step includes preflight checks to skip what's already configured and verification to confirm success.
