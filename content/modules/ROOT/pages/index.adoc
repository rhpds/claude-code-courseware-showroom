== Welcome

Claude Code Courseware is a set of *{module_count} interactive learning modules* for the RHDP operations team. Each module teaches a specific tool or integration through a guided, hands-on walkthrough that runs inside Claude Code.

[WARNING]
====
*These modules run locally on your workstation, not in a browser.* Claude Code is a CLI tool that must be installed on your Mac or Linux machine. This showroom is a reference guide only -- to run the interactive walkthroughs, follow the xref:getting-started.adoc[Getting Started] instructions to install Claude Code and the courseware plugin on your local machine.
====

== How It Works

. *Install Claude Code and the courseware plugin* on your local machine (see xref:getting-started.adoc[Getting Started])
. *Browse modules* in the navigation sidebar to understand what each one covers
. *Open your local terminal* and launch Claude Code
. *Run a module* by typing its command (e.g., `/learn-01-vertex-setup`)
. *Follow the walkthrough* -- Claude Code guides you through each step with verification

*Developer:* 01, 02, 03, 04, 06, 09, 24 -- environment setup, daily tools, security-first habits.

*Team lead / manager:* 01, 02, 15, 24 -- setup, project config, cost management, security awareness.
