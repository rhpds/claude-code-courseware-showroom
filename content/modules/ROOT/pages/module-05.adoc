== What You Will Learn

* How to configure the Atlassian Rovo MCP server (cloud-hosted, no local install)
* How to authenticate with your Red Hat Atlassian account via OAuth
* How to search Jira issues using JQL (Jira Query Language)
* How to create and update Jira issues
* How to add comments and transition issue workflows
* When to use API tokens for long-lived sessions vs OAuth

== Key Concepts

The Atlassian Rovo MCP server is cloud-hosted by Atlassian — no Podman, Docker, or local server needed. You configure Claude Code to point at `https://mcp.atlassian.com/v1/mcp` and authenticate via browser-based OAuth.

All MCP operations use your Red Hat Atlassian credentials and require an active account on `redhat.atlassian.net`. OAuth tokens expire after a few hours. For long-running sessions or automation, you can set up an API token instead.

The MCP server provides tools for:

* Searching issues with JQL queries
* Creating and updating issues (summary, description, assignee, custom fields)
* Adding comments with visibility control (public or restricted)
* Transitioning issue workflows (e.g., To Do → In Progress → Done)
* Looking up users and projects
* Reading issue metadata and field schemas

The configuration lives in `~/.claude/settings.json` at the user level, making Jira access available across all projects.

== Steps Overview

. Add `mcp-atlassian-prod` entry to `~/.claude/settings.json` pointing to the cloud URL
. Restart Claude Code to pick up the new MCP server
. Run `/mcp`, select `mcp-atlassian-prod`, and click Authenticate
. Sign in with your Red Hat credentials in the browser and grant access
. Return to Claude Code — the Atlassian MCP tools are now available
. Use `atlassianUserInfo` to verify the connection works
. (Optional) Set up an API token for long-lived sessions
. Search for Jira issues in the RHDPOPS project using JQL
